# Applied Inversive Geometry

🇺🇸 English README is available at [README.en.md](./README.en.md).

브라우저에서 동작하는 이미지 **반전 변환(inversion)** 도구입니다. 사진을 업로드하고 반전원(중심·반지름)을 정하면, 그 원에 대한 평면 반전을 적용한 결과를 실시간으로 보여줍니다. 여러 원을 합성해 Möbius 변환을 만들 수도 있고, 합성에서 자연스럽게 따라오는 군 구조와 Apollonian 가스킷 같은 프랙탈도 함께 시각화합니다.

> **반전(Inversion)** — 평면 위의 한 점 *O*와 반지름 *r*이 주어졌을 때, 점 *P* (≠ *O*)를 반직선 *OP* 위에 있고 *OP · OQ = r²* 을 만족하는 점 *Q*로 대응시키는 매핑.

**Version 0.4** — 변경 내역은 [CHANGELOG.md](./CHANGELOG.md) 참고.

### 3. GitHub Pages
레포 **Settings → Pages**에서 브랜치를 Deploy하면 공개 URL이 생깁니다.

## 📐 수학적 정의

중심 *O = (cx, cy)*, 반지름 *r*에 대해 출력 픽셀 *Q = (x, y)* 의 원본 좌표는

```
d² = (x - cx)² + (y - cy)²
P  = O + (Q - O) · (r² / d²)
```

- *d² ≈ 0* (중심): 원본 무한대 방향 → "정보 없음" 영역
- *P* 가 원본 이미지 밖: 마찬가지로 정보 없음 (또는 가장자리 클램프)
- 그 외: 해당 좌표 픽셀을 Bilinear/Nearest로 샘플링

여러 원의 합성은 N번의 반전을 차례로 적용하는 것과 같으며, N=2일 때 일반 Möbius 변환이 됩니다 (두 원의 위치에 따라 회전·평행이동 흐름·접한 흐름 중 하나).

**Inverse of a grid line**: 원본의 직선 `y = b` (`b ≠ cy`)는 결과 평면에서 중심 `(cx, cy + r²/(2(b-cy)))`, 반지름 `r²/(2|b-cy|)` 의 원으로 변환됩니다. 중심을 지나는 직선은 자기 자신.

자세한 수학 배경과 시각화 요소 설명은 페이지 좌상단 ⓘ 와 각 옵션 옆 ⓘ 에서 확인할 수 있습니다.

## 🛠 사용 팁

- **세부 조정**: 마우스/터치로 대략 맞춘 뒤 X%/Y%/반지름 입력 칸으로 미세 조정
- **저장 포맷**: 알파를 유지하려면 PNG/WEBP/AVIF. JPEG는 흰 배경에 자동 합성됨. iOS 사진 보관함은 PNG/JPEG/HEIC만 받습니다 (WEBP/AVIF는 다른 저장 경로로 빠짐)
- **애니메이션**: 짧게 (1~2초) 먼저 테스트한 뒤 길이를 늘리세요. 원본 해상도 + 고FPS + 4초 조합은 모바일 브라우저가 멈출 수 있어요. iOS Safari에서 저장이 안 되면 코덱을 바꿔서 다시 시도
- **프리셋**: 현재 설정을 슬롯에 저장하면 이미지가 바뀌어도 같은 "구도"가 그대로 적용됨 (좌표는 % 기반)
- **공유 링크**: 주소창 URL을 복사하면 받는 사람도 같은 구도. 이미지는 자기 것을 올려야 함
