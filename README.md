# Applied Inversion

🇺🇸 English README is available at [README.en.md](./README.en.md).

브라우저에서 동작하는 이미지 **반전 변환(inversion)** 도구입니다. 사진을 업로드하고 반전원(중심·반지름)을 정하면, 그 원에 대한 평면 반전을 적용한 결과를 실시간으로 보여줍니다.

> **반전(Inversion)** — 평면 위의 한 점 *O*와 반지름 *r*이 주어졌을 때, 점 *P* (≠ *O*)를 반직선 *OP* 위에 있고 *OP · OQ = r²* 을 만족하는 점 *Q*로 대응시키는 매핑.

---

## ✨ 기능

- 🖼 **이미지 업로드** — 로컬 파일을 드롭/선택해서 바로 처리 (JPG, PNG, WEBP 등)
- 🎯 **반전원 설정**
  - 캔버스를 **클릭/탭**하면 중심점이 그 위치로 이동
  - 중심점을 **드래그**해서 위치 조절
  - 점선 **경계를 드래그**해서 반지름 조절
  - 중심 X·Y (% 기준)와 반지름(px)을 **숫자로 직접 입력**도 가능 (양방향 동기화)
- ⚡ **실시간 결과** — 좌표·반지름을 바꾸는 즉시 오른쪽 캔버스에 반전 결과가 그려집니다.
- 🎨 **정보 없는 영역 처리** — 중심 근처의 픽셀은 원본 바깥 점에 매핑되므로 정보가 없습니다. 다음 중 선택:
  - 검정 / 흰색 / 사용자 지정 색 / 투명
- 💾 **저장** — PNG(기본) · JPEG · WEBP로 내보내기

## 🚀 실행 방법

별도 빌드/설치 없이 정적 HTML 한 파일이면 끝입니다.

### 1. 파일을 바로 열기
레포를 클론한 뒤 `index.html`을 브라우저에서 열기만 하면 됩니다.

### 2. 로컬 서버로 띄우기 (권장)
```bash
git clone https://github.com/udaque/applied-inversion.git
cd applied-inversion
python3 -m http.server 8000
# 또는: npx serve .
```
브라우저에서 `http://localhost:8000/` 접속.

### 3. GitHub Pages
레포 **Settings → Pages**에서 브랜치를 골라 Deploy하면 공개 URL로 접근할 수 있습니다.

## 📐 수학적 정의

중심 *O = (cx, cy)*, 반지름 *r*에 대해 출력 픽셀 *Q = (x, y)* 의 원본 좌표는

```
d² = (x - cx)² + (y - cy)²
P  = O + (Q - O) · (r² / d²)
```

- *d² < ε* (중심에서 너무 가까운 점): 원본 무한대 방향 → "정보 없음" 영역
- *P* 가 원본 이미지 밖: 마찬가지로 "정보 없음" 영역
- 그 외: 해당 좌표의 픽셀을 가져옵니다 (nearest-neighbor 샘플링)

원 위의 점(*d = r*)은 자기 자신으로 고정되고, 원 안쪽과 바깥쪽이 서로 교환됩니다.

## 🛠 사용 팁

- **세부 조정**: 마우스로 대략 맞춘 뒤 X%/Y%/반지름 입력 칸으로 미세 조정하세요.
- **저장 포맷**:
  - 알파(투명)를 유지하려면 PNG 또는 WEBP를 쓰세요. JPEG는 알파를 지원하지 않아 자동으로 흰 배경에 합성됩니다.
- **성능**: 처리 속도를 위해 표시 시 긴 변이 900px가 넘는 이미지는 비례 축소합니다. (`MAX_DIM = 900`)
