# Applied Inversion

🇺🇸 English README is available at [README.en.md](./README.en.md).

브라우저에서 동작하는 이미지 **반전 변환(inversion)** 도구입니다. 사진을 업로드하고 반전원(중심·반지름)을 정하면, 그 원에 대한 평면 반전을 적용한 결과를 실시간으로 보여줍니다.

> **반전(Inversion)** — 평면 위의 한 점 *O*와 반지름 *r*이 주어졌을 때, 점 *P* (≠ *O*)를 반직선 *OP* 위에 있고 *OP · OQ = r²* 을 만족하는 점 *Q*로 대응시키는 매핑.

## ✨ 기능

### 기본
- 🖼 **이미지 업로드** — 파일 선택 또는 좌측 빈 영역 클릭/탭
- 🎯 **반전원 설정**
  - 캔버스를 클릭/탭해서 중심점 점프
  - 중심점 드래그로 위치 조절, 점선 경계 드래그로 반지름 조절
  - 중심 X·Y (%)와 반지름(px)을 숫자로 직접 입력
- ⚡ **실시간 결과** — Web Worker + OffscreenCanvas로 메인 스레드 끊김 없음
- 🔍 **결과 캔버스 줌·팬**
  - 데스크탑: 마우스 휠로 커서 기준 확대/축소, 드래그로 이동, 더블클릭으로 초기화
  - 모바일: 두 손가락 핀치 줌, 한 손가락 드래그, 더블탭으로 초기화

### 고급 옵션
- 🎨 **정보 없는 영역 처리** — 검정 / 흰색 / 사용자 색 / 투명 / **가장자리 확장**(원본의 경계 픽셀을 클램프 샘플링)
- 🪡 **샘플링** — Nearest(빠름) / **Bilinear**(부드러움, 기본값)
- 💾 **원본 해상도로 저장** — 미리보기는 최대 900px로 축소해 빠르게 처리하고, 저장 시에는 원본 해상도로 다시 렌더링
- 📐 **그리드 오버레이** — 원본에 흰색 직선 격자를 표시하고, 결과 캔버스에는 그 격자의 inverse 이미지(중심을 지나는 원들)를 표시. 격자 간격 직접 지정 가능

### 저장 / 공유
- 💾 **저장** — PNG / JPEG / WEBP
  - 모바일에서는 Web Share API로 사진 보관함에 바로 저장 가능
- 📤 **SNS 공유** — Bluesky / X / Threads / Instagram / 기기 공유 / 링크 복사
  - Bluesky·X·Threads는 작성창이 텍스트 미리 채워진 채로 열리고, 이미지는 백그라운드에서 클립보드에 복사됨 → 작성창에 붙여넣기
  - 모바일에서 Web Share가 가능하면 OS share sheet로 직행
  - "현재 설정 포함" 토글로 해시 포함/비포함 링크 선택

### 상태 유지
- 🌐 **URL 해시** — 모든 설정(반전원 좌표 %, 반지름 %, 샘플링, 채움 모드, 그리드, 줌·팬, 언어)이 URL의 `#`에 기록됨 → 그대로 공유하면 같은 구도 재현
- 💽 **새로고침 복원** — 마지막 이미지는 IndexedDB에, 설정은 localStorage에 저장. 새 탭에서도 자동 복원
- 🌏 **한국어 / English 토글** — 헤더 셀렉터에서 선택, localStorage에 기억됨

```bash
cd applied-inversion
python3 -m http.server 8000
# 또는: npx serve .
```
브라우저에서 `http://localhost:8000/` 접속.

레포 **Settings → Pages**에서 브랜치를 골라 Deploy하면 공개 URL로 접근할 수 있습니다.

## 📐 수학적 정의

중심 *O = (cx, cy)*, 반지름 *r*에 대해 출력 픽셀 *Q = (x, y)* 의 원본 좌표는

```
d² = (x - cx)² + (y - cy)²
P  = O + (Q - O) · (r² / d²)
```

- *d² < ε* (중심에서 너무 가까운 점): 원본 무한대 방향 → "정보 없음" 영역
- *P* 가 원본 이미지 밖: 마찬가지로 "정보 없음" 영역 (또는 가장자리 클램프)
- 그 외: 해당 좌표의 픽셀을 가져옵니다 (Bilinear / Nearest 샘플링)

원 위의 점(*d = r*)은 자기 자신으로 고정되고, 원 안쪽과 바깥쪽이 서로 교환됩니다.

**그리드의 inverse**: 원본의 직선 `y = b` (`b ≠ cy`)는 결과 평면에서 중심을 지나는 원으로 변환됩니다 — 중심 `(cx, cy + r²/(2(b - cy)))`, 반지름 `r²/(2|b - cy|)`. 중심을 지나는 직선은 자기 자신으로 유지됩니다.

## 🛠 사용 팁

- **세부 조정**: 마우스로 대략 맞춘 뒤 X%/Y%/반지름 입력 칸으로 미세 조정
- **저장 포맷**:
  - 알파(투명)를 유지하려면 PNG 또는 WEBP. JPEG는 알파가 없어 흰 배경에 자동 합성
  - 모바일에서 사진 보관함 저장 시 iOS는 PNG/JPEG/HEIC만 받습니다 (WEBP는 보관함 외 저장으로 빠짐)
- **성능**: 처리 속도를 위해 미리보기는 긴 변이 900px가 넘는 이미지를 비례 축소(`MAX_DIM = 900`). 저장과 공유는 원본 해상도로 다시 렌더
- **공유**: Bluesky·X·Threads는 작성창에 텍스트가 자동 채워지므로 이미지만 Ctrl/⌘ V로 붙여넣으면 됩니다
